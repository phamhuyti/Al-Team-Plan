Sáu vai trò V1

Mỗi agent trả JSON contract — không free-form prose làm output chính.

Manager
điều phối

Lập kế hoạch, chọn agent, chốt quyết định. Không sửa code.

Architect
thiết kế

Trade-off, kiến trúc, phương án thay thế và rủi ro.

Researcher
evidence

Thu thập phương án + web search (DuckDuckGo / mock).

Coder
code

Đọc/sửa file qua tool, đề xuất test, chuẩn bị commit.

Reviewer
chất lượng

Approve / request changes / reject với issue có mức độ.

Red Team
phản biện

Tấn công giả định — chứng minh phương án có thể sai.

Hướng dẫn nhanh

Chọn tab theo nhu cầu. Demo mock chạy hoàn toàn offline.

1

Clone & cài package

# Python 3.11+
git clone https://github.com/phamhuyti/Al-Team-Plan.git
cd Al-Team-Plan
python3 -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp .env.example .env
2

Kiểm tra test

pytest -q
1

Init project demo

AI_TEAM_PROVIDER=mock ai-team init --name demo --purpose "Demo app"
AI_TEAM_PROVIDER=mock ai-team plan "Thêm authentication"
AI_TEAM_PROVIDER=mock ai-team implement TASK-001 --yes
AI_TEAM_PROVIDER=mock ai-team status

--yes chỉ dùng CI/demo — không bật trên NAS production.

1

Gắn key trong .env

OPENAI_API_KEY=sk-...
AI_TEAM_PROVIDER=openai
AI_TEAM_MODEL=gpt-4o
2

Plan & implement

ai-team plan "Thêm rate limiting"
ai-team implement TASK-001
ai-team replay 1
1

Serve từ project đã init

cd /path/to/your/project
ai-team serve
# mở http://localhost:8080/

Tab: Dashboard · Tasks · Live Chat · Approvals · Cost Monitor. Project root cố định lúc startup.

1

Compose trên NAS

cp .env.example .env
docker compose up --build
# API + UI :8080
PROJECT_WORKSPACE=/volume1/projects/my-app docker compose up --build
